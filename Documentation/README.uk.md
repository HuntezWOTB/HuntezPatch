**HuntezPatch v1.02** — генератор модів для **Tanks Blitz** (Lesta Games) та **World of Tanks Blitz** (Wargaming).
Збирає три моди: **HiddenTanks** (показує приховані танки в дереві досліджень), **AutoRanksOFF**
(прибирає рангові блокування інтерфейсу ангара) та **RandomTankSelector** (додає кнопку-кубики випадкового танка в ангар).

## Моди

| Мод | Що робить | Файли (відносно `Data/`) |
|-----|------------|------------------------------|
| **HiddenTanks** | Показує ВСІ приховані танки в дереві досліджень (преміумні, колекційні, тестові, видалені). Купівля й далі залежить від акцій розробників — мод лише показує техніку. Сортування прихованих за рівнем: **звичайні → колекційні → преміумні**, всередині групи за класом (**ЛТ → СТ → ВТ → ПТ**). | `Configs/TechTree/*_tree.yaml` (9 націй), `XML/item_defs/vehicles/*/list.xml` (9 націй) |
| **AutoRanksOFF** | Прибирає рангові блокування: кнопка «В бій» завжди видима, підказки про ранг приховані, події прокачування видалені, святкування «У вашого танка з'явився ранг!» не спливає. | `UI/Screens3/Lobby/Hangar/Hangar.yaml`, `UI/Screens3/Lobby/Hangar/Squad/SquadView.yaml`, `UI/Screens3/Lobby/Inventory/Inventory.yaml`, `UI/Screens3/Lobby/Inventory/TankProgress/AchievementsTab.yaml` |
| **RandomTankSelector** | Додає кнопку з двома кубиками на панель танків ангара — натискання обирає випадковий танк. Іконка кубиків генерується при кожній генерації. | `UI/Screens3/Lobby/Hangar/TanksPanel/TanksPanel.yaml`, `UI/Screens3/Lobby/Hangar/TanksPanel/TanksPanel.actions`, `Gfx/Lobby/icons/randomtankselector_button_icon.packed.webp` (+ @2x, нові файли) |

Та сама інформація є в програмі за кнопкою **?** на картці мода.

## Можливості

- Три моди в одній утиліті, вибираються незалежно (картки-чекбокси).
- Операції **Генерація** (стейджинг: temp → бекап → заміна) та **Експорт** (папка `Mod` + `Backup` для поширення).
- Режими файлів **DVPL / NON-DVPL**; DLC-файли завжди DVPL.
- **Підтримка DLC (мікрооновлень)** з авто-підказкою та відкриттям папки `packs` в один клік.
- Вбудований **провідник** (вкладки `Файли гри` / `Файли DLC`): ліниве дерево, підсвітка файлів модів, колонка статусу `МОДИФІКОВАНО`, режим «Лише файли модів».
- Зручний журнал (копіювання `Ctrl+C` / `Ctrl+A`, меню правою кнопкою, обидві розкладки).
- Прогрес-бар з числом файлів, фонові операції (інтерфейс не висить).
- 6 мов інтерфейсу, світла/темна теми, портативні налаштування.

## Вимоги

- **Windows** з **Python 3.8+** (`python --version`).
- Залежності з `requirements.txt`: `lz4`, `PyYAML`, `Pillow` (`tkinter` вбудований).

## Встановлення

```bat
autoinstall_modules.bat
start_program.bat
```

Або вручну:

```bat
pip install -r requirements.txt
python main.py
```

Встановлення не потрібне — програма портативна. Налаштування зберігаються в `config.json` поруч із `main.py`.

## Швидкий старт

1. Вкажіть **папку гри** (ту, де лежить `Data/`).
2. Виберіть **проєкт** (`Wargaming` / `Lesta Games`) та **режим DVPL** (див. нижче).
3. Позначте потрібні моди.
4. Натисніть **▶ Виконати** → **Генерація (Заміна)** (або **Генерація (Експорт)** для переносного пакета).
5. Запустіть гру й перевірте. Відкат у будь-який момент — **↩ Повернути оригінали**.

## Режими операцій

| Режим | Поведінка |
|-------|-----------|
| **Генерація (Заміна)** | Файли спочатку модифікуються в тимчасовій папці (не в грі!), оригінали бекапляться, потім готові файли копіюються на місце. DLC-файлам ставиться атрибут «тільки читання», як чекає клієнт. |
| **Генерація (Експорт)** | Папка гри не чіпається. Пакет пишеться в `result/<назва>_<версія>/`: `Mod/` (патчені файли) та `Backup/` (оригінали). |

## Режими DVPL

| Режим | Поведінка |
|-------|-----------|
| **DVPL** | Контейнери `.dvpl` розпаковуються → правляться → запаковуються назад. Обирайте його, якщо в папці гри лежать `.dvpl` (наприклад, Steam-клієнт). |
| **NON-DVPL** | Обробляються лише вже розпаковані (plain) файли гри; `.dvpl` пропускаються з підказкою в журналі. |

> **DLC-файли ЗАВЖДИ DVPL** незалежно від режиму — мікроапдейти розпакованими не постачаються.

## DLC (мікрооновлення)

Якщо гра привезла мікрооновлення, його файли перекривають базові — їх теж треба патчити:

| Проєкт | Папка `packs` |
|--------|---------------|
| Wargaming | `%userprofile%/AppData/Local/wotblitz/packs` |
| Lesta Games | `%userprofile%/Documents/TanksBlitz/packs` |

- Увімкніть **Змінювати файли DLC**, щоб їх захопити.
- Якщо DLC-файли модів є, а галочка вимкнена — програма попередить.
- Кнопка **DLC-папка** відкриває вибірку (`Wargaming` / `Lesta Games`) з відкриттям потрібної папки `packs` у провіднику.

## Структура експорту

```
result/BlitzMods_<моди>_<версія>/
├── Mod/
│   ├── Data/    <- патчені файли гри (plain або .dvpl, як лежали)
│   └── packs/   <- патчені DLC-файли (завжди .dvpl, кидати в packs гри)
└── Backup/
    ├── Data/    <- оригінали файлів гри
    └── packs/   <- оригінали DLC-файлів
```

## Бекап і відновлення

- Генерація зберігає бекапи в `<гра>/BlitzMods_Backup/<мод>/{Game,DLC}/...`.
- **↩ Повернути оригінали** копіює їх назад (DLC — знову read-only), а потім видаляє папку бекапа мода — збережені оригінали своє відпрацювали, нова генерація створить бекап заново.
- Провідник позначає статусом **МОДИФІКОВАНО** кожен файл із сигнатурою генератора (`HuntezPatch - Generated`), включно з усіма папками вище. Після відновлення мітки гаснуть самі.

## Огляд інтерфейсу

- **Шапка**: назва, кнопка мови (`RU/EN/…`, вибірка), кнопка теми (`☀/☾`).
- **Шлях до гри**: рядок на всю ширину з індикатором валідності та кнопкою Огляд справа.
- **Ліва колонка** (гортається): картки модів (клік — вкл/викл, `?` — довідка), сегменти Проєкт і DVPL, блок DLC, кнопки дій.
- **Справа**: великі вкладки — **Журнал**, **Файли гри**, **Файли DLC**. У файлових вкладок є Оновити / У провіднику та режим **Лише файли модів** (ієрархія за модами з розміром і станом Гра/DLC).
- **Статус-бар**: індикатор стану, живий прогрес-бар (`Прогрес: 42% · 5/12`, у простої `© Huntez`), версія.

Усі налаштування зберігаються автоматично й відновлюються при запуску. При найпершому запуску мова й тема беруться із системи.

## Вирішення проблем

| Симптом | Рішення |
|---------|---------|
| `Невірний шлях до гри (немає папки Data)` | Вкажіть папку, в якій лежить `Data/`. |
| `Немає файлу … пропускаємо` в NON-DVPL | Гра зберігає тут `.dvpl` — увімкніть режим **DVPL**. |
| `! NON-DVPL пропускає DVPL-файл` | Інформаційна підказка, не помилка — див. вище. |
| `Немає бекапа для <мод>` при відновленні | Спочатку хоча б раз згенеруйте мод. |
| Попап про ранг однаково спливає | Перегенеруйте AutoRanksOFF (потрібен майстер-вимикач `ranksAvailable`), спершу повернувши оригінал. |
| Замість кубиків фіолетова шахівниця | Перегенеруйте RandomTankSelector, спершу повернувши оригінал (бракує файла іконки). |
| Гра оновилась | Проганяйте генерацію заново й звіряйтеся з мітками МОДИФІКОВАНО. |

## Структура проєкту

```
HuntezPatch/
├── main.py                  # точка входу
├── requirements.txt
├── start_program.bat / autoinstall_modules.bat
├── config.json              # генерується: ваші налаштування (не в git)
├── core/                    # DVPL-кодек, файлові операції, рушії модів (Mods/hidden_tanks, Mods/autoranks, Mods/random_tank)
├── gui/                     # інтерфейс (плитки, провідник, попапи, журнал)
├── locales/                 # рядки інтерфейсу ru/en/uk/de/tr/pl
├── Documentation/           # ця інструкція 6 мовами
└── result/                  # генерується: експортні пакети (не в git)
```

Під час роботи створюються лише `config.json` і `result/` — решта сирці.
Повний список — у [.gitignore](../.gitignore).
