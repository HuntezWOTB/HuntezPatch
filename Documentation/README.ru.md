**HuntezPatch v1.01** — генератор модов для **Tanks Blitz** (Lesta Games) и **World of Tanks Blitz** (Wargaming).
Собирает три мода: **HiddenTanks** (показывает скрытые танки в дереве исследований), **AutoRanksOFF**
(убирает ранговые блокировки интерфейса ангара) и **RandomTankSelector** (добавляет кнопку-кубики случайного танка в ангар).

## Моды

| Мод | Что делает | Файлы (относительно `Data/`) |
|-----|------------|------------------------------|
| **HiddenTanks** | Показывает ВСЕ скрытые танки в дереве исследований (премиум, коллекционные, тестовые, удалённые). Покупка по-прежнему зависит от акций разработчиков — мод только показывает технику. Сортировка скрытых по уровню: **обычные → коллекционные → премиум**, внутри группы по классу (**ЛТ → СТ → ТТ → ПТ**). | `Configs/TechTree/*_tree.yaml` (9 наций), `XML/item_defs/vehicles/*/list.xml` (9 наций) |
| **AutoRanksOFF** | Убирает ранговые блокировки: кнопка «В бой» всегда видима, подсказки про ранг скрыты, события прокачки удалены, празднование «У вашего танка появился ранг!» не всплывает. | `UI/Screens3/Lobby/Hangar/Hangar.yaml`, `UI/Screens3/Lobby/Hangar/Squad/SquadView.yaml`, `UI/Screens3/Lobby/Inventory/Inventory.yaml`, `UI/Screens3/Lobby/Inventory/TankProgress/AchievementsTab.yaml` |
| **RandomTankSelector** | Добавляет кнопку с двумя кубиками в панель танков ангара — по нажатию выбирается случайный танк. Иконка кубиков генерируется при каждой генерации. | `UI/Screens3/Lobby/Hangar/TanksPanel/TanksPanel.yaml`, `UI/Screens3/Lobby/Hangar/TanksPanel/TanksPanel.actions`, `Gfx/Lobby/icons/randomtankselector_button_icon.packed.webp` (+ @2x, новые файлы) |

Та же информация есть в программе по кнопке **?** на карточке мода.

## Возможности

- Три мода в одной утилите, выбираются независимо (карточки-чекбоксы).
- Операции **Генерация** (стейджинг: temp → бэкап → замена) и **Экспорт** (папка `Mod` + `Backup` для распространения).
- Режимы файлов **DVPL / NON-DVPL**; DLC-файлы всегда DVPL.
- **Поддержка DLC (микрообновлений)** с авто-подсказкой и открытием папки `packs` в один клик.
- Встроенный **проводник** (вкладки `Файлы игры` / `Файлы DLC`): ленивое дерево, подсветка файлов модов, колонка статуса `МОДИФИЦИРОВАН`, режим «Только файлы модов».
- Удобный журнал (копирование `Ctrl+C` / `Ctrl+A`, меню по правому клику, обе раскладки).
- Прогресс-бар с числом файлов, фоновые операции (интерфейс не виснет).
- 6 языков интерфейса, светлая/тёмная темы, портативные настройки.

## Требования

- **Windows** с **Python 3.8+** (`python --version`).
- Зависимости из `requirements.txt`: `lz4`, `PyYAML`, `Pillow` (`tkinter` встроен).

## Установка

```bat
autoinstall_modules.bat
start_program.bat
```

Или вручную:

```bat
pip install -r requirements.txt
python main.py
```

Установка не нужна — программа портативная. Настройки хранятся в `config.json` рядом с `main.py`.

## Быстрый старт

1. Укажите **папку игры** (ту, где лежит `Data/`), например `C:/Program Files/Steam/steamapps/common/World of Tanks Blitz`.
2. Выберите **проект** (`Wargaming` / `Lesta Games`) и **режим DVPL** (см. ниже).
3. Отметьте нужные моды.
4. Нажмите **▶ Выполнить** → **Генерация (Замена)** (или **Генерация (Экспорт)** для переносимого пакета).
5. Запустите игру и проверьте. Откат в любой момент — **↩ Вернуть оригинал**.

## Режимы операций

| Режим | Поведение |
|-------|-----------|
| **Генерация (Замена)** | Файлы сначала модифицируются во временной папке (не в игре!), оригиналы бэкапятся, затем готовые файлы копируются на место. DLC-файлам ставится атрибут «только чтение», как ждёт клиент. |
| **Генерация (Экспорт)** | Папка игры не трогается. Пакет пишется в `result/<название>_<версия>/`: `Mod/` (патченные файлы) и `Backup/` (оригиналы). |

## Режимы DVPL

| Режим | Поведение |
|-------|-----------|
| **DVPL** | Контейнеры `.dvpl` распаковываются → правятся → запаковываются обратно. Выбирайте его, если в папке игры лежат `.dvpl` (например, Steam-клиент). |
| **NON-DVPL** | Обрабатываются только уже распакованные (plain) файлы игры; `.dvpl` пропускаются с подсказкой в журнале. |

> **DLC-файлы ВСЕГДА DVPL** независимо от режима — микроапдейты распакованными не поставляются.

## DLC (микрообновления)

Если игра привезла микрообновление, его файлы перекрывают базовые — их тоже надо патчить:

| Проект | Папка `packs` |
|--------|---------------|
| Wargaming | `%userprofile%/AppData/Local/wotblitz/packs` |
| Lesta Games | `%userprofile%/Documents/TanksBlitz/packs` |

- Включите **Изменять DLC файлы**, чтобы их захватить.
- Если DLC-файлы модов есть, а галочка выключена — программа предупредит.
- Кнопка **DLC-папка** открывает выборку (`Wargaming` / `Lesta Games`) с открытием нужной папки `packs` в проводнике.

## Структура экспорта

```
result/BlitzMods_<моды>_<версия>/
├── Mod/
│   ├── Data/    <- патченные файлы игры (plain или .dvpl, как лежали)
│   └── packs/   <- патченные DLC-файлы (всегда .dvpl, кидать в packs игры)
└── Backup/
    ├── Data/    <- оригиналы файлов игры
    └── packs/   <- оригиналы DLC-файлов
```

## Бэкап и восстановление

- Генерация хранит бэкапы в `<игра>/BlitzMods_Backup/<мод>/{Game,DLC}/...`.
- **↩ Вернуть оригинал** копирует их обратно (DLC — снова read-only).
- Проводник помечает статусом **МОДИФИЦИРОВАН** каждый файл с сигнатурой генератора (`HuntezPatch - Generated`), включая все папки выше. После восстановления метки гаснут сами.

## Обзор интерфейса

- **Шапка**: название, кнопка языка (`RU/EN/…`, выборка), кнопка темы (`☀/☾`).
- **Путь к игре**: строка во всю ширину с индикатором валидности и кнопкой Обзор справа.
- **Левая колонка** (прокручивается): карточки модов (клик — вкл/выкл, `?` — справка), сегменты Проект и DVPL, блок DLC, кнопки действий.
- **Справа**: большие вкладки — **Журнал**, **Файлы игры**, **Файлы DLC**. У файловых вкладок есть Обновить / В проводнике и режим **Только файлы модов** (иерархия по модам с размером и состоянием Игра/DLC).
- **Статус-бар**: индикатор состояния, живой прогресс-бар (`Прогресс: 42% · 5/12`, в простое `© Huntez`), версия.

Все настройки (язык, тема, путь, моды, проект, режим, DLC, геометрия окна) сохраняются автоматически и восстанавливаются при запуске. При самом первом запуске язык и тема берутся из системы.

## Решение проблем

| Симптом | Решение |
|---------|---------|
| `Неверный путь к игре (нет папки Data)` | Укажите папку, в которой лежит `Data/`. |
| `Нет файла … пропускаем` в NON-DVPL | Игра хранит тут `.dvpl` — включите режим **DVPL** (или распакуйте файлы). |
| `! NON-DVPL пропускает DVPL-файл` | Информационная подсказка, не ошибка — см. выше. |
| `Нет бэкапа для <мод>` при восстановлении | Сначала хотя бы раз сгенерируйте мод. |
| Попап про ранг всё равно всплывает | Перегенерируйте AutoRanksOFF (нужен мастер-выключатель `ranksAvailable`), предварительно вернув оригинал. |
| Вместо кубиков фиолетовая шахматка | Перегенерируйте RandomTankSelector, предварительно вернув оригинал (не хватает файла иконки). |
| Игра обновилась | Прогоните генерацию заново и сверьтесь с метками МОДИФИЦИРОВАН. |

## Структура проекта

```
HuntezPatch/
├── main.py                  # точка входа
├── requirements.txt
├── start_program.bat / autoinstall_modules.bat
├── config.json              # генерируется: ваши настройки (не в git)
├── core/                    # DVPL-кодек, файловые операции, движки модов (Mods/hidden_tanks, Mods/autoranks, Mods/random_tank)
├── gui/                     # интерфейс (плитки, проводник, попапы, журнал)
├── locales/                 # строки интерфейса ru/en/uk/de/tr/pl
├── Documentation/           # эта инструкция на 6 языках
└── result/                  # генерируется: экспортные пакеты (не в git)
```

При запуске создаются только `config.json` и `result/` — остальное исходники.
Полный список — в [.gitignore](../.gitignore).
